Zero-Knowledge Cryptography

How Yapergram Protects Your Data

Unlike traditional platforms that store plaintext messages or central decryption keys, Yapergram utilizes a zero-knowledge architecture. The backend functions strictly as an encrypted envelope routing broker.

Security Layer Cryptographic Standard Implementation Details
Key Exchange Curve25519 (X3DH) Triple Diffie-Hellman handshake establishing shared master secret
Message Cipher AES-256-GCM / Poly1305 Authenticated symmetric encryption with unique 12-byte initialization vectors
Forward Secrecy Double Ratchet Algorithm DH Ratchet + KDF Ratchet generating brand-new keys per message packet
Ephemeral Queue Auto-Purging SQLite Server permanently wipes encrypted payloads upon delivery confirmation

Frequently Asked Questions

Everything you need to know about Yapergram.

Is Yapergram really 100% free forever?

Yes. Yapergram operates on a decentralized, zero-credit-card architecture utilizing GitHub Pages, Render Free Tier containers, and client-side PWA technology. There are no subscriptions or hidden fees.

Can anyone read my messages on the server?

No. All messages are encrypted directly on your device before transmission. The server only sees random ciphertext bytes and cannot read messages, view media, or forge identities.

How do I install Yapergram on my iPad or Android phone?

Open client/index.html in Safari (iPad) or Chrome (Android) and tap "Add to Home Screen". Yapergram installs instantly as a native full-screen standalone application with push notifications.

How do Locked Chats work?

You can set a 4-digit PIN on any conversation. Locked chats are hidden in a dedicated folder and cannot be opened or read without entering the correct PIN.
